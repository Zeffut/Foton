What a spawner is told to spawn.

Vanilla parity: net.minecraft.world.level.SpawnData and net.minecraft.world.entity.EquipmentTable. Both live here rather than in foton-core because the trial-spawner config registry is generated data and has to name them.

The light check SpawnData.CustomSpawnRules.isValidPosition needs a level, so it stays in foton-core; what is here is the range pair it reads.
