Module predicate

Expand description

Evaluating the predicates an advancement criterion asks about.

Vanilla parity: net.minecraft.advancements.predicates plus the LootItemConditions a ContextAwarePredicate is built from. [foton_registry::advancement::predicate] holds the plain data; this is the half that needs a world, a player and the entity a trigger fired for.

Vanilla evaluates every one of these against a LootContext built by EntityPredicate.createContext or by the trigger itself, so PredicateContext carries exactly the LootContextParams an advancement ever reads: THIS_ENTITY, ORIGIN, BLOCK_STATE and TOOL, plus the player whose level and position vanilla takes them from.

Anything Foton cannot answer fails closed. A predicate that silently passes hands out an advancement vanilla gates behind a state nobody checked, which is strictly worse than one that never fires – every such gap is marked with a // Not implemented: comment naming the vanilla check it stands in for.
