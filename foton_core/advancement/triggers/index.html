foton_core::advancement

Module triggers 

Source
Expand description

Firing a criterion’s trigger for one player.

Vanilla parity: CriteriaTriggers and SimpleCriterionTrigger.trigger. Vanilla keeps a per-player listener map and adds or removes entries as criteria are met; Foton’s advancement set never changes, so the criteria a trigger could award are indexed once for the whole server in super::TRIGGER_INDEX, and the player narrows that to the ones still listening.

A trigger nothing calls awards nothing, which is what vanilla does before the trigger is invoked – it is not the same as a criterion that always passes. The vanilla call sites Foton has not reached are marked with a // Not implemented: comment naming the trigger rather than granting it.
