Expand description

Something that happened, which a listener may observe and possibly stop.

Events are identified by their DowncastTypeKey rather than by TypeId. AGENTS.md requires it for anything a plugin can extend: TypeId is sound within one linked build and meaningless across two, and the whole point of this bus is that something outside this build will use it.

Provided Methods§

Source

fn is_cancelled(&self) -> bool

Whether this event has already been stopped.

An event that cannot be stopped always answers false. That is why this lives here with a default rather than in a separate trait: dispatch has to ask every event the same question, and a bus that could only ask some of them would need two dispatch paths for no gain.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
