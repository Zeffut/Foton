Expand description

The live state of one trial spawner.

Vanilla’s detectedPlayers and currentMobs are hash sets. Foton keeps them as insertion-ordered vectors so that the player an ejection pays out first is the first one the spawner saw rather than whichever the hash happened to put in front; one reward per player either way.
