Bell block entity.

Vanilla parity: BellBlockEntity. A rung bell does three things a block state cannot hold: it swings for fifty ticks, it tells everything within thirty-two blocks that it was rung, and – if any of those were raiders – it resonates for two seconds and then lights every raider within forty-eight blocks up for three.

The swing itself is the client’s, driven by the block event this sends; the server keeps the counter only because the resonance is measured from it.
