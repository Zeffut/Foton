Vanilla parity: ConduitBlockEntity.updateShape.

Returns the frame blocks found, which is empty when the 3x3x3 pocket around the conduit is not all water – vanilla returns early there and leaves its list cleared, which is what keeps a drained conduit from counting as hunting.
