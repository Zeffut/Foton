Module sculk_shrieker

Expand description

Sculk shrieker block-entity storage and shriek response.

Vanilla parity: SculkShriekerBlockEntity.

A shrieker hears through a vibration listener like the sensors do, but its listenable events are only sculk_sensor_tendrils_clicking: it answers a sensor that just fired near it, not the footstep the sensor heard.

Four warnings summon a warden. The count is not kept here – it lives on the player, so walking to a different shrieker does not restart it.
