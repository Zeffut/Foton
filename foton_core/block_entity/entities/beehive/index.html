Module beehive

Expand description

Beehive block entity implementation.

Vanilla parity: BeehiveBlockEntity. The hive is a container for bees: it swallows one whole, keeps its saved NBT for as long as the bee stays in, and puts it back out of the front face when its timer runs out – raising the honey level if the bee came home carrying nectar.
