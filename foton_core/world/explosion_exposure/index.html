Module explosion_exposure 

Source
Expand description

The block states an explosion reads while measuring how exposed each entity is.

Vanilla parity: ServerExplosion.getSeenPercent clips a grid of rays from every entity in reach to the center – 27 rays for a primed TNT. In a chain reaction of a few hundred TNT that is more than ten thousand clips per explosion, all through the same few thousand blocks, and looking each of them up through the chunk table again made exposure the most expensive part of a blast. Each block is read once here and kept for the rest of the explosion.

An entity’s damage can change blocks before the next entity is measured (an end crystal blows up inside the loop), and vanilla measures the next one against the changed world. The cache therefore forgets everything as soon as the world has committed a block change since it filled.
