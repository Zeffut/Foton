Module explosion_rays 

Source
Expand description

The rays that decide which blocks an explosion breaks.

Vanilla parity: the ray loop of ServerExplosion.calculateExplodedPositions. It is a function of a few closures rather than of a World so that it can be tested against a plain reference, and because the only thing worth changing about it is how it looks blocks up.

A blast sends 1352 rays over ranges that overlap almost entirely: for a TNT that is about 26 000 steps over roughly a thousand distinct blocks. Looking each step up through the chunk table, and asking a Vec whether the position was already taken, cost more than 4 ms per explosion; two hundred TNT in one tick froze the server for a second. Each distinct block is looked up once here, and “already taken” is a flag.
