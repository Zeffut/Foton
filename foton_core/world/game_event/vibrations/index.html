Module vibrations 

Source
Expand description

Vibrations: the layer sculk and the warden hear the world through.

Vanilla parity: net.minecraft.world.level.gameevent.vibrations. A game event is instantaneous and reaches every listener in range at once; a vibration is a game event that had to travel, one tick per block, and only the best one heard in a tick is allowed to travel at all. Those two rules plus the occlusion test are what separate a sculk sensor from a pressure plate.
