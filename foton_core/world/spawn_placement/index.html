Module spawn_placement 

Source
Expand description

Where a mob is allowed to appear.

Vanilla parity: SpawnPlacementTypes, plus the per-entity-type table that SpawnPlacements builds in code rather than in data. Nearly every mob wants solid ground, so that is the default; the exceptions are listed here exactly as vanilla registers them, because they cannot be derived from the mob category. A drowned is a monster and spawns in water, a strider is a monster and spawns in lava, and a phantom is a monster that spawns in mid-air.
