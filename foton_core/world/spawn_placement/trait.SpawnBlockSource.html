Expand description

Somewhere the spawn rules can read blocks from.

Vanilla passes a LevelReader, which a chunk still being generated satisfies just as well as a running world. Foton’s World and its WorldGenRegion share no such trait, so the placement tests take this instead and both spawners get the same answers from the same code.
