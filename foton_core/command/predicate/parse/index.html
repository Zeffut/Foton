foton_core::command::predicate

Module parse 

Source
Expand description

Lowers a datapack predicate/*.json file into the typed predicates of [foton_registry::advancement::predicate].

Vanilla parity: LootItemCondition.DIRECT_CODEC, which reads either one typed condition or a list of them (an implicit all_of), with the entity sub-predicate map of EntityPredicate.CODEC inside.

Every object is read key by key through Object, and anything left over is an error. A predicate Foton cannot model is therefore refused at load, with the path of the key, instead of loading as one that asks less than the datapack wrote and answering true for the wrong things.
