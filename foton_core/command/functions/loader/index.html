Datapack discovery and raw resource reading.

Vanilla parity: the FolderRepositorySource view of <level>/datapacks filtered through FileToIdConverter. Foton keeps the datapack directory beside the save root because its function library is server-wide, the way vanilla’s is, while Foton’s worlds each have their own save directory.
