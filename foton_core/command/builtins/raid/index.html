The /raid debug command.

Vanilla parity: net.minecraft.server.commands.RaidCommand. It is the only way to start a raid without waiting out a Bad Omen, and check is the only way to read a raid’s counters from inside the game, so it is what an in-world test drives.

Vanilla’s sound local subcommand is a client-side debug horn played five blocks east of the caller; it is left out because it tests the client’s positional audio rather than anything the server does.
