Module bossbar 

Source
Expand description

The /bossbar command.

Vanilla parity: net.minecraft.server.commands.BossBarCommands. It is the only way to put a bar on a player’s screen that no boss is behind, and the only reader and writer of the named bars a domain persists.

Every set refuses a change that would change nothing. That is not decoration: /bossbar set <id> value 5 returning its value makes it a useful execute store source, and a no-op that quietly reported success would make a datapack loop think it had made progress.
