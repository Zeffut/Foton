Function local_clock_time

fn local_clock_time() -> String
Expand description

Returns the local wall-clock time as HH:MM:SS.

Vanilla parity: the DateTimeFormatter.ofPattern("HH:mm:ss") of CloseableCommandBlockSource.

Foton has no local-timezone source, so this is UTC. The stamp is cosmetic – it only ever appears in the command block editor’s output line.
