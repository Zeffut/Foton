Expand description

A raid on one village.

Vanilla parity: Raid.

Fields§

§id: i32

The key this raid is filed under in super::Raids.

Vanilla looks this up with Raids.getId by identity. Foton stores it, because identity comparison against an Arc would need the map lock from inside a tick that already released it.

§num_groups: i32

Vanilla parity: Raid.numGroups, fixed by the difficulty at creation.

Finds a spot on the ring outside the village to drop a wave on.
