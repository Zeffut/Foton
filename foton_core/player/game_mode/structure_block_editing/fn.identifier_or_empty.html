fn identifier_or_empty(value: &str) -> Identifier

Parses an identifier field, falling back to minecraft:empty.

Vanilla reads these with readIdentifier, which rejects a malformed one at the codec; Foton keeps the string and falls back here so a bad editor entry cannot drop the connection.
