The chest minecart.

Vanilla parity: MinecartChest and AbstractMinecartContainer. A rolling chest: it runs on rails like any cart, and a right-click opens it rather than seating anybody, because there is nowhere to sit.

Mineshafts generate these with a loot table attached. The table is rolled the first time somebody opens the cart, matching ContainerEntity.unpackChestVehicleLootTable.
