Area effect cloud.

Vanilla parity: AreaEffectCloud. The lingering half of alchemy: a patch of ground that keeps working after the bottle is gone. What makes it a distinct thing rather than a slow splash is that it charges for use – every entity it catches shrinks it – so one cloud can serve a crowd once or one target several times, but not both.
