Provided Methods§

Source

fn set_size(&self, size: i32, update_health: bool)

Sets the size, and with it everything the size decides.

Vanilla parity: AbstractCubeMob.setSize, plus whatever the subclass adds on top of it.

Source

fn deals_damage(&self) -> bool

Returns whether this cube hurts what it touches.

Vanilla parity: AbstractCubeMob.isDealsDamage. A tiny slime is harmless, which is the whole reason players let them pile up – and the magma cube overrides exactly this to say that a tiny one is not.

Source

fn jump_delay(&self) -> i32

Returns ticks until the next hop.

Vanilla parity: AbstractCubeMob.getJumpDelay.

Source

fn is_tiny(&self) -> bool

Returns whether this cube is the smallest kind.

Source

fn max_health_for_size(&self, size: i32) -> f64

Returns the health a cube of this size has.

Vanilla parity: AbstractCubeMob.setcubeMobHealth, which squares the size. The sulfur cube overrides exactly this and grows linearly instead, which is why it is a hook rather than a line of apply_size.
