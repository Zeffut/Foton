The zoglin’s brain.

Vanilla parity: the static getActivities, initCoreActivity, initIdleActivity and initFightActivity of net.minecraft.world.entity.monster.Zoglin. Vanilla keeps them on the mob class rather than in a separate Ai helper; Foton splits them out so the entity file stays about the entity.
