Expand description

The trading state of one merchant mob.

Fields§

§world: Weak<World>§entity_id: i32§offers: SyncMutex<MerchantOffers>§offers_built: AtomicBool

Vanilla keeps offers null until something asks for it, so that a villager which never meets a player never rolls its trades. Foton keeps the list itself behind the Merchant seam, so the “not yet built” state is this flag.

§trading_player: SyncMutex<Option<Uuid>>§level: AtomicI32

Mirrors VillagerData.level so the trading screen can draw its badge without reaching back through the world on every sync.

§xp: AtomicI32§last_traded_player: SyncMutex<Option<Uuid>>§update_merchant_timer: AtomicI32§increase_profession_level_on_update: AtomicBool§can_restock: bool

Vanilla parity: canRestock, true only for a villager.

§show_progress_bar: bool

Vanilla parity: showProgressBar, false for a wandering trader.
