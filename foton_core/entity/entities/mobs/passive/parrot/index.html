Module parrot 

Source
Expand description

Parrot entity.

Vanilla parity: Parrot and ShoulderRidingEntity. The only tameable mob that flies, the only one that rides a shoulder, and the only one that tells you what is hiding in the dark by imitating it.

Gap: Parrot.doPush stops a parrot shoving players around. Foton resolves pushing on the pushed entity rather than the pusher, so there is no per-pusher hook to override yet.
