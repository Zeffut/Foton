The allay’s brain.

Vanilla parity: net.minecraft.world.entity.animal.allay.AllayAi. Two activities and no fight set at all: an allay never attacks anything. What it does instead is find the item it was handed a copy of, and carry it back to whoever handed it over – or to the note block it last heard, which is what turns a pair of allays into a sorting machine.
