Ocelot entity.

Vanilla parity: Ocelot. The ocelot is the counter-example to the rest of this batch: since 1.14 it cannot be tamed at all. Fish buys trust, which only stops it running away – it never follows, never sits, and never gets an owner. It is an Animal, not a TamableAnimal, and the trust flag is one synced boolean.
