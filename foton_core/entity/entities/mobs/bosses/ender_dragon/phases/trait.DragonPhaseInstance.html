Expand description

One phase’s behaviour.

Vanilla parity: DragonPhaseInstance, with AbstractDragonPhaseInstance’s bodies as the trait defaults. doClientTick is not carried: every override of it in vanilla only spawns particles, which is client-local work.

fn as_sitting_flaming(&self) -> Option<&DragonSittingFlamingPhase>

Returns this as the breathing phase, when it is that phase.

Vanilla reaches a specific phase through the generic getPhase(EnderDragonPhase<T>), whose type parameter carries the concrete class. A Rust trait object has no such parameter, so the three phases another phase needs to talk to say so themselves.
