Module mob_effect_hooks 

Source
Expand description

Vanilla MobEffect.onMobHurt and MobEffect.onMobRemoved.

applyEffectTick was the only effect hook Foton had, which left four effects inert: Infested spawned no silverfish when its carrier was hurt, Wind Charged burst nothing on death, Weaving laid no cobwebs and Oozing dropped no slimes. Those four are the whole payoff of the trial-chamber and ominous-vault loop, so without them the reward is decorative.

The hurt hook takes neither the damage source nor the amount, which vanilla passes: InfestedMobEffect is the only implementation and it reads neither. A future effect that needs them can widen the signature – the call site has both in hand.
