fn set_dashing(&self, is_dashing: bool)

Applies vanilla AbstractNautilus.setDashing.

Vanilla’s onSyncedDataUpdated arms the cooldown the first time DASH changes with the clock at zero, which is the only thing that starts the server’s cooldown when a rider’s handleStartJump raises the flag. Foton has no synced-data change hook, so the same rule lives here: every vanilla path that writes DASH goes through setDashing, so the two are equivalent.

fn use_nautilus_player_item(&self, player: &Player, hand: InteractionHand)

Applies vanilla AbstractNautilus.usePlayerItem, which hands back the water bucket a bucket of fish leaves behind.

Rust has no super, and this is what Mob::use_player_item is overridden with, so the else branch spells Mob.usePlayerItem out rather than calling it – calling it would come straight back here.
