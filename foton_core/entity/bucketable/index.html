Expand description

Mobs that fit in a bucket.

Vanilla parity: net.minecraft.world.entity.Bucketable. The interface is two halves that have to agree: the mob writes itself into a bucket when a player scoops it up, and MobBucketItem reads it back out when the bucket is emptied. Foton had only the second half, and it spawned a fresh mob rather than the one that went in; this is the first half plus the state the second half was missing.
