Expand description

A mob a water bucket can pick up.

Vanilla parity: the Bucketable interface. Vanilla’s two saveDefaultData / loadDefaultData statics are save_default_data_to_bucket_tag and load_default_data_from_bucket_tag here, because Rust has no static interface methods.
