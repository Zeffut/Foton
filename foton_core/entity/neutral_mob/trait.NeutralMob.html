Expand description

A mob that stays angry at whoever provoked it.

Vanilla parity: the NeutralMob interface.

fn start_persistent_anger_timer(&self)

Starts the anger timer for however long this kind of mob sulks.

Vanilla parity: startPersistentAngerTimer, which each mob implements with its own random range – twenty to thirty-nine seconds for most.

fn update_persistent_anger( &self, world: &Arc<World>, stay_angry_if_target_present: bool, )

Reconciles the anger with the current target, once per tick.

Vanilla parity: updatePersistentAnger. stay_angry_if_target_present is what separates a wolf, which keeps refreshing its grudge while it can see you, from an enderman, which does not.
