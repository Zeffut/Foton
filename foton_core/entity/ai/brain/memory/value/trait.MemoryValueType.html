Expand description

How one Rust type maps onto a MemoryValue.

Implemented once per value shape; super::MemoryModuleType is generic over this trait, which is what makes a mistyped set_memory a compile error rather than a silently ignored write.

Required Methods§

Source

fn into_memory_value(self) -> MemoryValue

Wraps this value for storage in a brain.

Source

fn from_memory_value(value: &MemoryValue) -> Option<Self>

Reads this value back out, or None when the stored shape differs.

Provided Methods§

Source

fn from_nbt(_value: &BorrowedNbtTag<'_, '_>) -> Option<MemoryValue>

Reads a value of this shape back from NBT.

Returning None means vanilla registers the memory without a codec, so nothing was written for it in the first place.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
