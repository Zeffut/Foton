The memory kinds vanilla registers, transcribed from net.minecraft.world.entity.ai.memory.MemoryModuleType.

Only the memories Foton’s ported sensors, behaviors and mobs actually use are declared; vanilla registers around a hundred, and the rest arrive with the mobs that read them.
