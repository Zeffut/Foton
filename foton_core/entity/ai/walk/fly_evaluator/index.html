Module fly_evaluator 

Source
Expand description

Node evaluation for mobs that fly.

Vanilla parity: FlyNodeEvaluator. It extends the walking evaluator rather than replacing it: the mob’s bounding box is classified the same way, but open air counts as somewhere to be rather than somewhere to fall through, and a step may go up or down as freely as sideways. That is the whole difference between a parrot and a chicken.
