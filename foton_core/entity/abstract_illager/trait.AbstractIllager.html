fn considers_entity_as_ally_illager(&self, other: &dyn Entity) -> bool

Returns vanilla AbstractIllager.considersEntityAsAlly.

The tag holds the four illagers, so a pillager, a vindicator, an evoker and an illusioner never target one another. Vanilla also requires both entities to be teamless, which is free here: Foton puts no entity on a scoreboard team.

Vanilla’s canAttack override – refusing to hit a baby villager – is absent with the villagers it names.
