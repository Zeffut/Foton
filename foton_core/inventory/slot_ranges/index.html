Module slot_ranges 

Source
Expand description

The named numeric slots commands address entities and containers by.

Vanilla parity: SlotRanges. The numbers are not an inventory layout – they are a flat namespace laid over every kind of slot an entity can have, so that one command argument can name a villager’s third inventory slot (mob.inventory.2), a horse’s saddle (saddle) and a chest’s fortieth slot (container.39) without knowing what it is talking to.

Ids collide on purpose. horse.chest and player.cursor are both 499, and horse.0..horse.3 overlap player.crafting.0..player.crafting.3; what separates them is which entity is asked, not which name was used.
