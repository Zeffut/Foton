Hopper menu.

Vanilla parity: HopperMenu. Five slots in a row, then the player inventory. Layout:

  • Slots 0 to 4: the hopper
  • Slots 5 to 31: main inventory (27)
  • Slots 32 to 40: hotbar (9)
