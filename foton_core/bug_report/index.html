Module bug_report 

Source
Expand description

Bug reports filed by players from inside the game.

A test session’s whole value is what the testers noticed, and the gap between noticing and reporting is where most of it is lost. So the report is filed where the player is standing, and everything that can be captured without asking – who, where, which world, which build – is captured rather than typed.

Reports are appended to reports/bugs.jsonl, one JSON object per line. Append-only and line-delimited on purpose: concurrent writers cannot corrupt each other’s records the way a rewritten array would, a truncated last line costs one report rather than the file, and every ordinary tool reads it.
