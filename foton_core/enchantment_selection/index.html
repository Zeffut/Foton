Module enchantment_selection 

Source
Expand description

Choosing which enchantments an enchanting table offers, and rolling them.

Vanilla parity: the selection half of EnchantmentHelper – getEnchantmentCost, getAvailableEnchantmentResults, selectEnchantment and enchantItem. Foton’s crate::enchantment_helper covers the other half, applying enchantments once an item has them; nothing here had an implementation, which is why an enchanting table had nothing to offer.
