Bundle item behavior.

Vanilla parity: BundleItem. The client-only halves of that class – the fullness bar (isBarVisible, getBarWidth, getBarColor), the grid layout (getNumberOfItemsToShow) and getTooltipImage – are left out: a server only ships the minecraft:bundle_contents component and the client draws from it. Vanilla’s awardStat(Stats.ITEM_USED) is also left out because Foton has no statistics system yet.
