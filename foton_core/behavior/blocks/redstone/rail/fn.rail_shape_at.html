pub fn rail_shape_at(state: BlockStateId) -> Option<RailShape>
Expand description

Which way a rail runs, or None if state is not a rail.

Vanilla parity: the state.getValue(((BaseRailBlock)state.getBlock()).getShapeProperty()) that every minecart starts from. A straight-only rail stores its shape in a property with six values rather than ten, but both are called shape and both hold a RailShape, so reading it by name works for either.
