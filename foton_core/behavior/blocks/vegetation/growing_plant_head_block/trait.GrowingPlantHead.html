Expand description

The vanilla GrowingPlantHeadBlock age contract.

Vanilla reaches it with state.getBlock() instanceof GrowingPlantHeadBlock; Foton’s head blocks compose GrowingPlantHeadBlock instead of extending it, so the hierarchy check goes through BlockBehavior::as_growing_plant_head.
