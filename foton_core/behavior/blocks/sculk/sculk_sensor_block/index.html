Sculk sensor behavior, plain and calibrated.

Vanilla parity: SculkSensorBlock and CalibratedSculkSensorBlock.

A vibration reaching the block entity’s listener ends in activate_sculk_sensor, which drives the phase machine, the redstone output, the comparator read and the resonance that amethyst beside the sensor re-emits.
