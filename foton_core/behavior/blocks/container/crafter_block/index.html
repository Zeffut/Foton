Crafter block behavior.

Vanilla parity: CrafterBlock. A crafting table that a redstone pulse works: four ticks after the signal arrives it matches its nine slots against the recipe book, takes one item out of each filled slot, and pushes the result into whatever container it faces – or throws it, if there is none.

Two things make it more than an automatic crafting table. Its slots can be switched off, so a recipe with a hole in it keeps the hole while a hopper pours items in. And it fires once per rising edge, not continuously, so a held signal crafts exactly one item.
