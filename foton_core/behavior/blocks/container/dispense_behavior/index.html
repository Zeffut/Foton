Module dispense_behavior 

Source
Expand description

What a dispenser does with each item.

Vanilla parity: DispenseItemBehavior and the registry DispenseItemBehavior.bootStrap fills. A dispenser is only interesting because of this table: without it every item is simply thrown, which is what vanilla itself does for anything with no entry.
