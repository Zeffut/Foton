How readily each block catches fire and burns away.

Vanilla parity: FireBlock.bootStrap, which fills two Object2IntMap<Block> on the fire block itself, once, at startup. Foton keeps the same pair of numbers, indexed by block id so the spread scan around a fire – fifty-odd positions every fire tick – stays a plain lookup.
