Module startup_gate 

Source
Expand description

Keeps players out until a freshly started server keeps up. Keeps players out until a freshly started server keeps up with its ticks.

The first seconds after boot are the heaviest a server has: worlds finish loading, chunks around the spawn generate, plugins warm up. A player let in then joins a server that is seconds behind and sees it lag. The listener opens only once the recent ticks fit their budget – or after [MAX_WAIT], so a machine that is simply slow still takes players.
