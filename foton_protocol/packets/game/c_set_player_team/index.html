Clientbound team packet: a team’s look, and who is on it.

Vanilla parity: ClientboundSetPlayerTeamPacket. A byte after the team’s name selects the operation; adding and changing carry the team’s parameters, and adding, joining and leaving carry a list of entries. Without it the client never learns a team exists, so a prefix, a suffix or a colored name set on the server is never drawn.
