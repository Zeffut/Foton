Expand description

Clientbound update advancements packet – what the advancement screen draws and how far the player has got through it.

Vanilla parity: ClientboundUpdateAdvancementsPacket, together with the AdvancementHolder, Advancement and DisplayInfo stream codecs it delegates to. Vanilla keeps the removals in a set and the progress in a map; Foton keeps ordered vectors, so the same packet always encodes to the same bytes and can be tested against them.
