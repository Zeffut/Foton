FIRST WORLD

Get started

Install Foton and start your world.

Foton is pre-alpha. Use it for testing, not yet for a server you rely on.

1. Install

Open a terminal in the folder where you want the server, then run one command. Foton installs in that folder.

$ curl -fsSL https://foton.zeffut.fr/install.sh | sh
> irm https://foton.zeffut.fr/install.ps1 | iex

The installer asks for the server name, port, player limit, authentication and difficulty, then creates the configuration files.

2. Start and join

Join

In Minecraft Java Edition, open Multiplayer, add a server, then enter localhost when the server runs on the same machine.

If you chose another port during installation, enter localhost:port.

Start

$ ./foton
> .\foton.exe

Update

Stop the server, then run the command for your system from its folder. Your worlds and settings stay in place.

$ curl -fsSL https://foton.zeffut.fr/install.sh | sh -s -- --update
> iex "& { $(irm https://foton.zeffut.fr/install.ps1) } -Update"
