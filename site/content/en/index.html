Exploring doesn't slow anyone down

New land and its lighting are worked out while the game keeps running, instead of pausing it. One player heading somewhere new doesn't cost everyone else their frame rate.

Everything is a settings file

Your worlds, who is allowed to do what, and how the server behaves are plain text files you can open and read. Put in a value that cannot work and the server says so when it starts, instead of breaking a week later.

Your farms keep working

Spigot and the servers built on it speed things up by quietly changing some of the game's rules, and redstone builds and farms break when they do. Foton doesn't make that trade — it finds its speed elsewhere.

Nothing else to install

One file to run. No Java to set up, no memory settings to guess at, and no start-up options copied off a forum post.

Running in one command.

The world builds itself, saves, and comes back the way you left it. Your players join with the Minecraft they already have, on the usual port.

Foton doesn't run plugins yet — not Bukkit, not Spigot, not Fabric. If your server depends on them today, this isn't the one for you yet.
