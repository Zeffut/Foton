The tick stays free

Chunk generation, lighting and packet handling run beside the game loop instead of inside it. What players feel as lag is work that never had to be there.

Your server, your rules

Worlds, permission groups and server behaviour are plain TOML, checked against a schema on every boot. A typo is a startup error, not a mystery three days later.

No surprises for your players

Redstone, mob behaviour, loot and world generation match the game they already know. Nothing is reimplemented from memory.

One binary, no runtime

No JVM to size, no garbage collector to tune, no flags to copy from a forum post. Drop it next to a config folder and start it.

Running in one command.

The world generates, saves to the Anvil format vanilla uses, and reloads where you left it. Point a Minecraft {{ mc_target }} client at port 25565 and play.

Foton runs no Bukkit, Spigot or Fabric plugin — it is its own server, and a plugin API is not built yet. If your server needs one today, Foton is not that server today.

Installation and first boot Configuration
