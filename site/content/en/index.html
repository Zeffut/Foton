A Minecraft server that refuses to guess.

An independent Java Edition server, written in Rust. It behaves like vanilla because it is written against vanilla's own source — not against someone's memory of it.

Get started Source
$ docker run -p 25565:25565 ghcr.io/zeffut/foton:nightly

Vanilla, not an approximation

Gameplay, protocol, registries and world generation are written against the decompiled source. Where a faster design would change what a player sees, the player wins.

Nothing transcribed by hand

Every registry, block, item and worldgen value comes out of an extractor. A struct named after its vanilla class is its own registration — there is no list to keep in sync.

Concurrent where vanilla allows

Chunk generation, lighting and packet processing run off the tick. Gameplay stays synchronous, because vanilla's semantics depend on the order things happen in.

Configured, not patched

Worlds, permissions and server behaviour are TOML, validated against schemas the server ships with. Every key is documented, and the documentation is generated from those schemas.

Running in one command.

The world generates, saves to the Anvil format vanilla uses, and reloads where you left it. Point a Minecraft {{ mc_target }} client at port 25565 and play.
