PREMIER MONDE

Démarrer

Installez Foton et lancez votre monde.

Foton est en pré-alpha. Utilisez-le pour tester, pas encore pour un serveur auquel vous tenez.

1. Installer

Ouvrez un terminal dans le dossier où vous voulez installer le serveur, puis exécutez une seule commande. Foton s'installe dans ce dossier.

$ curl -fsSL https://foton.zeffut.fr/install.sh | sh
> irm https://foton.zeffut.fr/install.ps1 | iex

Le programme vous demande le nom du serveur, le port, le nombre de joueurs, l'authentification et la difficulté. Il crée ensuite les fichiers de configuration.

2. Lancer et rejoindre

Rejoindre

Dans Minecraft Java Edition, ouvrez Multijoueur, ajoutez un serveur, puis entrez localhost si vous jouez sur la même machine.

Si vous avez choisi un autre port pendant l'installation, entrez localhost:port.

Lancer

$ ./foton
> .\foton.exe

Mettre à jour

Arrêtez le serveur puis lancez la commande correspondant à votre système depuis son dossier. Vos mondes et vos réglages restent en place.

$ curl -fsSL https://foton.zeffut.fr/install.sh | sh -s -- --update
> iex "& { $(irm https://foton.zeffut.fr/install.ps1) } -Update"
