The process-wide shared key, if init_shared has been called.

§Security

None is the safe default. It means Bedrock support was never initialized, and it must mean no Floodgate login is ever accepted: the login path is expected to treat an uninitialized key exactly like a rejected handshake, never as a transient condition worth retrying.
