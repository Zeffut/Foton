The secret Foton and its Geyser share.

Sixteen raw bytes, which is what Geyser’s AesKeyProducer.produceFrom reads a key file as. Not PEM despite the conventional name – Geyser reads the file whole and hands it to SecretKeySpec.

Everything about a Bedrock player’s identity rests on this file staying secret: it is the only thing standing between a forged handshake and total impersonation.
