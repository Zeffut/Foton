Module unheard_damage 

Source
Expand description

The last damage of each entity that no plugin handler heard.

Paper records every hit that went through as the victim’s getLastDamageCause, whether or not a plugin listens to damage events, and a plugin may read it later – in a death handler, say. Building that event in Java for every hit costs a JNI crossing each; a nuke damages thousands of dropped items in one tick. When no damage handler exists the facts wait here, and Java builds the event only if a plugin asks for it.
