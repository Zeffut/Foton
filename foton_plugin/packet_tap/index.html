Module packet_tap 

Source
Expand description

Foton’s packet tap, answered by the Java side.

This is what a packet library such as PacketEvents stands on. Foton hands over every packet as protocol bytes, on the connection’s own network task, and foton.PacketBridge hands back what its listeners decided.

The tap is installed only when the Java side asks for it, so a server whose plugins never touch raw packets never pays for a crossing.
