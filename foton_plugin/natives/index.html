foton_plugin

Module natives 

Source
Expand description

What the Java side asks Foton, answered.

Registered with RegisterNatives rather than found by symbol lookup: Foton is one binary and its symbols are its own business, and a JVM searching a statically linked executable for Java_foton_Native_serverName is a way to discover at runtime that the linker discarded it.

Every function here is called from a JVM thread, not from the game tick. World mutations remain scheduler-owned; narrowly scoped plugin registries (such as runtime recipes) expose their own synchronized write path.
