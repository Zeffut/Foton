Module relay 

Source
Expand description

Paper’s events that Foton learned to carry after the first set.

Every crossing here has the same shape, so it is written once: the facts go over as strings to a static method of foton.EventRelay, Java builds its event, runs the handlers, and answers with one string that the subscription below reads back. Fields in an answer are separated by FIELD; a boolean is 1 or 0. A crossing that fails – no JVM thread, a throwing handler – answers None, and every subscription treats that as “nobody objected”, because a broken plugin must not be able to freeze the game.
