foton::rcon

Module packet 

Source
Expand description

Wire format for the Source RCON protocol.

Vanilla parity: net.minecraft.server.rcon.thread.RconClient.send and PktUtils. Every field is a little-endian i32, the payload is a NUL-terminated string, and one more NUL closes the frame. The length prefix counts everything after itself, so it is the payload length plus the two ids, the terminator and the pad.
